Local cheat sheet PDFs served directly by the app.

Currently here:
- matplotlib-cheatsheet.pdf
- scikit-learn-cheatsheet.pdf
- seaborn-cheatsheet.pdf

Each is referenced in src/app/resources/page.tsx as /cheatsheets/<filename>.
To add another, drop the PDF in this folder and add a matching entry to
the RESOURCES array with the same /cheatsheets/<filename> path.
